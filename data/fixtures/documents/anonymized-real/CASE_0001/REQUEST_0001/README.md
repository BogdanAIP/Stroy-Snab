# REQUEST_0001

This directory contains a rebuilt `anonymized-real` XLSX derivative.

The workbook is created from an explicit allowlist and does not preserve the original Office container. It contains only a neutral document identifier, a generic procurement-line header, one retained technical product line, its quantity/unit text, and an empty comment cell.

Excluded from the derivative: original filename/document number, company or person identity, project/object identity, date, supplier/contractor references, contacts, requisites, comments, formulas, links, hidden content, embedded objects and reverse mapping to the private source.

The source document remains private and is not part of this repository.
