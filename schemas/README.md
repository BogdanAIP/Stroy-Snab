# Schemas

Canonical machine-readable domain schemas will live here once accepted by a stage.

Expected families include:

- source document / extraction result;
- procurement line;
- procurement-case graph node/link and lifecycle relation;
- normalized item evidence;
- match/compatibility/fulfilment decision;
- supplier/offer evidence;
- procurement recommendation;
- external adapter envelopes.

Stage 0 intentionally does not freeze detailed schemas. Stage 1P defines only the safe anonymized case/document identity needed for public fixtures; Stage 1A derives document/line schemas and Stage 1B derives lifecycle-link schemas from measured real-document requirements.
