# Schemas

Canonical machine-readable domain schemas will live here once accepted by a stage.

Expected families include:

- source document / extraction result;
- procurement line;
- normalized item evidence;
- match/compatibility decision;
- supplier/offer evidence;
- procurement recommendation;
- external adapter envelopes.

Stage 0 intentionally does not freeze detailed schemas. Stage 1 will derive the first schema from measured real-document requirements.
