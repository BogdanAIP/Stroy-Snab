# Data Policy

## Public repository rule

`BogdanAIP/Stroy-Snab` публичный. Сырые реальные закупочные документы не коммитятся по умолчанию.

К закрытым данным относятся, в частности:

- УПД, счета, накладные, договоры и коммерческие предложения;
- ИНН/КПП/банковские и контактные реквизиты, если они не нужны публичному fixture;
- подписи, печати, персональные данные;
- договорные/закрытые цены;
- внутренние номера заявок и иная коммерческая связка документов.

## Private evaluation corpus

Реальные документы из пользовательской ChatGPT Library используются как внешний private corpus. Репозиторий хранит только описание набора и воспроизводимые ожидаемые структуры, не позволяющие восстановить закрытый документ.

Private corpus может включать разные поставщики, даты, форматы PDF, многострочные наименования, единицы и количества. Он является основным источником realistic failure cases.

## Public fixtures

Разрешены:

1. полностью синтетические документы;
2. вручную обезличенные фрагменты после проверки;
3. структурированные fixtures с заменёнными поставщиками, номерами документов, ценами и реквизитами;
4. минимальные текстовые случаи, воспроизводящие ошибку parser/matcher без раскрытия исходного документа.

Каждый public fixture должен иметь provenance label:

`synthetic | redacted-derived | public-source`.

## Gold labels

Gold labels для private corpus могут храниться вне GitHub и использовать стабильный непрозрачный `case_id`, например `priv_upd_0001`, без имени поставщика и номера документа.

Минимальные labels Stage 1:

- дата документа;
- номер документа;
- поставщик (private label; в публичной метрике может быть hashed/pseudonymous);
- строки: raw name, unit, quantity;
- source locator/page where available.

Цены/НДС/суммы добавляются только когда они нужны конкретному evaluation stage.

## Derived artifacts

Логи/evidence не должны случайно сериализовать полный исходный документ. Тесты и CI работают только на public fixtures. Private evaluation запускается локально/в разрешённой среде и публикует агрегированные метрики и безопасные error classes.

## External datasets

До добавления внешнего классификатора/справочника фиксируются источник, версия, дата, лицензия и допустимое использование. Данные с non-commercial или неоднозначной лицензией не становятся production dependency коммерчески ориентированного продукта без отдельного решения.
